# 键盘统计分析

> **🌐 语言切换**：简体中文 · [**English**](./README.en.md)

**你的 Mac 键盘，正在偷偷替你生成一份个人数据报告。**

这是一个 macOS 桌面应用：它安静地驻留在后台，记录你每一次按键、每一个快捷键、每一记鼠标点击，再把它们变成一张清晰的统计面板，和一个随时可以提问的 AI 数据分析助手。

## 它能为你做什么？

**📊 看得见的"手指GDP"**
- 实时统计今日/昨日按键量，清楚掌握自己一天真正的"产出"
- 最常用按键 Top10，了解你的黄金手指是谁
- 运行时长累计，记录你专注工作的时间线

**⌨️ 全局无感记录**
- 跨所有应用生效：写代码、做文档、打游戏、刷网页，全部一键记录
- 普通按键、组合快捷键、鼠标左/右/中键，分类清晰互不混淆
- 数据只存在于你的本机 SQLite，绝不上传，绝不出门

**🤖 会"查数"的 AI 助手**
- 不用 SQL，开口就问："今天哪个键按得最多？""最近一周我点鼠标和敲键盘的比例？"
- 内置 Agent 自动连接数据库执行查询，结果直接对话式返回
- 不联网也能有一个，配置自由：千帆 / OpenAI / DeepSeek / 通义 / 自定义端点

**🔑 一句话配置，即刻开聊**
- 内置主流服务商预设，选服务商 → 粘贴 API Key → 保存即用，无需改任何配置文件
- 保存时自动测试连接，失败立刻告诉你怎么了，杜绝"发出去了没反应"

## 为什么选它？

- **隐私友好**：全键盘以外的行为一律不碰，统计不离开这台 Mac
- **轻量安静**：后台常驻，不打断、不弹窗，想查看时一键展开
- **开发者友好**：TypeScript 全栈 + 清晰的模块划分，源码干净可读，魔改不头疼
- **开箱即发**：内置构建配置，一条命令打包 dmg/zip，随时分发给你的朋友

## 快速开始

### 前置依赖

- macOS 10.15+
- Node.js ≥ 22.18（建议 22 LTS 或更高）
- npm

### 安装

```bash
npm install
```

### 开发运行

```bash
npm run dev
```

> 首次运行需在「系统设置 → 隐私与安全性 → 辅助功能」授予本应用权限，否则无法全局统计按键。

### 打包分发

```bash
npm run dist        # 生成 macOS .dmg + .zip（输出到 dist/）
```

## AI 助手配置

统计功能完全离线可用；AI 助手需自行接入一个大模型 API：

1. 点右下角「💬 AI 助手」
2. 未配置时点「去配置」（未接入前助手会明确引导，不会静默失效）
3. 选择服务商并粘贴 **API Key**
4. 点「保存」→ 自动测连 → 通过即生效，无需重启

密钥只存本地 `ai-config.json`（已 gitignore），或用 `.env` 作后备（见 `.env.example`）。

## 目录结构

```
src/
├── main/        # Electron 主进程：窗口、全局监听、事件采集、IPC
├── preload/     # contextBridge 暴露受限 API
├── renderer/    # React UI：统计面板、AI 聊天、设置
├── mastra/      # AI Agent、Hono server、SQLite 只读工具
└── shared/      # 类型契约、SQLite 数据访问层、AI 配置模块
```

## 数据位置

- 开发模式：项目根 `keyboard_stats.db`
- 正式安装：`~/Library/Application Support/keyboard-stats/`
